# Genomeia MCP для настольной игры

Один раз подключите Genomeia к своему локальному помощнику. После этого можно попросить, например, «Прочитай справочник клеток. Собери организм с листом и мышцей, покажи стадии роста и картинку. Сохрани его как “Лист с мышцей”».

## Подключение

1. Распакуйте комплект в постоянную папку с правом записи. Для JAR нужна Java 21. В Windows откройте **Play with MCP.cmd**. В Linux/macOS запустите `java -jar Genomeia.jar --enable-mcp`. На время работы с помощником оставьте это окно открытым.
2. Откройте **MCP setup.cmd** или выполните `java -jar Genomeia.jar --mcp-config`. Игра напечатает команды с абсолютными путями к Java и этой копии игры.
3. Для **Codex** выполните выведенную строку `codex mcp add …`. Для **Claude Code** выполните строку `claude mcp add …`. В Windows строки предназначены для PowerShell. В **Claude Desktop** добавьте выведенную запись `genomeia` в раздел `mcpServers` конфигурации локальных серверов. Сохраните уже существующие записи.
4. Перезапустите клиент или откройте новую сессию. Попросите «Вызови get_status в Genomeia и назови экран игры». В ответе должен быть текущий экран, например `MenuScreen`. Если игра закрыта, каталог инструментов остаётся виден, а вызов вернёт сообщение о запуске с `--enable-mcp`.

Актуальные настройки клиентов приведены в [документации Codex](https://developers.openai.com/codex/mcp/), [Claude Code](https://code.claude.com/docs/en/mcp) и [Claude Desktop](https://support.claude.com/en/articles/10949351-getting-started-with-local-mcp-servers-on-claude-desktop).

Игра и локальный MCP-клиент должны работать под одной учётной записью. При перемещении JAR повторите настройку с новым путём. Обычный запуск игры оставляет мост выключенным. Игра завершает соединение при закрытии окна. Помощник получает данные игры через свой клиент.

## Что можно прочитать

| Запрос | Результат |
| --- | --- |
| `get_status`, `list_genomes` | Текущий экран, маршрут, доступность проверки роста, черновики и имена геномов игрока и встроенной библиотеки. |
| `get_catalog` | Ключи и описания доступных клеток, формулы, правила деления и готовый пример стадий в формате установленной игры. В редакторе учитывается его палитра. |
| `read_genome` | Исходные стадии, деления, мутации и связи. В режиме `cells` возвращает геометрию взрослого тела с ID клеток. Источником служит имя из библиотеки, ID черновика или `editor:` для открытого редактора. |
| `read_growth` | Клетки на выбранном тике роста черновика или открытого редактора. Ответ содержит `lastTick`. Позиции соответствуют раскладке, которую показывает редактор. |
| `read_state` | Между двумя тиками мира снимает страницу клеток, организмов, физических или направленных нейросвязей. Для клетки доступны положение, скорость, энергия и сигналы. В открытом редакторе читает выращенное тело и сообщает выбранный тик шкалы. |
| `measure_organism` | Для одного живого организма возвращает номер тика, стадию, центр тела, среднюю скорость, сумму энергии и число клеток каждого типа. |

Для наблюдения за гусеницей поставьте её в симуляцию и попросите помощника перечислить организмы через `read_state(view="organisms")`. Вызовите `measure_organism` со значениями `slot` (аргумент `organism`) и `generation` из ответа. Повторите измерение через несколько тиков. Разность координат центра показывает перемещение, а типы, энергия и число концов физических связей помогают заметить распад организма. Поколение позволяет обнаружить повторное использование слота после смерти. Каждый вызов читает своё значение тика. Для постраничного сравнения клеток и обоих концов связи на одном тике поставьте симуляцию на паузу. Индексы концов связей соответствуют `slot` клеток. Концы нейросвязи выдаются в направлении передачи сигнала.

## Создание и проверка

Получите `exampleStages` из `get_catalog` и передайте массив в `create_genome(name, stages)`. Первая стадия начинается с зиготы с ID 0. Ключ в `cellActions` обозначает исходную клетку. При делении ребёнку нужны свободный ID, тип и угол в радианах. В `physicalLink` ключ обозначает ID второй клетки, длина задаётся в единицах мира. Ключи типов и формул можно копировать из справочника. Стадии существующего организма можно прочитать через `read_genome`.

Черновик получает собственный `draft:…` и хранится в памяти окна игры. Для другого варианта создайте новый черновик с изменёнными стадиями. В памяти остаются восемь последних черновиков. Первая версия принимает до 128 стадий и 256 клеток на создаваемый геном. Большие библиотечные геномы доступны для чтения по страницам с `offset` и `limit`.

В главном меню или в разделе «Геномы» вызовите `validate_genome(id)`. Игра вырастит организм штатным расчётом редактора, построит связи, посчитает взрослые клетки и подготовит снимок. Ошибки структуры содержат стадию и ID проблемной клетки, когда они известны. Открытый рабочий редактор использует тот же расчётный мир, поэтому для первого выращивания черновика нужно выйти из редактора. Проверка описывает рост. Поведение взрослого организма можно наблюдать отдельно в запущенном мире.

Вызовите `preview_genome(id)` для получения PNG прямо в ответе MCP. Затем `save_genome(id)` сохранит запечённый файл через библиотеку и вернёт его имя. Из главного меню откроется экран «Геномы». При совпадении имени с другим содержимым игра подберёт свободное имя. Повтор того же сохранения вернёт существующий файл. Пользовательские файлы располагаются в папке `genomes` рядом с игровым JAR. Для работы с существующей библиотекой используйте папку своей игры или скопируйте нужные .genome в новую установку.

## Сборка и проверка из исходников

В корне проекта запустите `./gradlew :lwjgl3:genomeMcpDist` (Windows: `gradlew.bat :lwjgl3:genomeMcpDist`). Комплект появится в `lwjgl3/build/genome-mcp`. После `gradlew clean` каталог сборки удаляется, поэтому для постоянной игры скопируйте комплект отдельно.

Сквозная проверка запускает независимые процессы игры и стандартного ввода-вывода, использует временную библиотеку и реальный OpenGL. Для проверки нужны Java 21, Node.js и графический сеанс.

```
node lwjgl3/src/verification/mcp/smoke.mjs lwjgl3/build/genome-mcp/Genomeia.jar
node lwjgl3/src/verification/mcp/smoke.mjs lwjgl3/build/genome-mcp/Genomeia.jar GoGenomeEditor
node lwjgl3/src/verification/mcp/smoke.mjs lwjgl3/build/genome-mcp/Genomeia.jar GoSimulation
```
