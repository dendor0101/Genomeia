# Отдельные опыты частоты стадий, 21.10.2026

База всех патчей: `473c2a8`. Каждый патч применяется **отдельно** к этой базе.
Они не складываются автоматически. 32×1 и блочный обход сохранены.

| Патч | Изменение | Результат проверки |
|---|---|---|
| `contacts.patch` | Контакт только в конце каждого подшага: 64→32 | Записи проходят; повторный таран имеет одно проникновение |
| `momentum32.patch` | Баланс импульса за полный тик | Первый опыт: последняя коррекция могла превысить предел скорости; не использовать как принятый вариант |
| `momentum-capped.patch` | То же + последний ограничитель скорости | Предел выдержан; на тике 3670 другой записи две клетки внутри ткани |
| `medium4.patch` | Вязкость, нормальное и общее сопротивление раз в 4 подшага | Четыре записи проходят; ручная оценка ещё нужна |
| `medium32.patch` | Те же стадии один раз в тик | Четыре записи проходят; гребок меняется сильнее |

Полный отчёт: [stage-frequency-2026-10-21.md](../../stage-frequency-2026-10-21.md).
Сводки исходных замеров, блоки A/B и SHA-256 патчей: [results.json](results.json).
Самоповтор новой версии не является совпадением с исходными H игрока.

В текущей рабочей копии включён `medium4` с поясняющими комментариями. Остальные
варианты остаются отдельными опытами. Основная `alpha-0.2.4` не изменена.

Чтобы воспроизвести отдельный вариант, в чистой рабочей копии базы применить
соответствующий patch, затем выполнить (пример для medium4):

```text
gradlew --no-daemon :physics:test :physics-lab:test :physics-lab:writeBenchmarkClasspath :lwjgl3:compileLabKotlin
python physics-lab/tools/freeze_classpath.py physics-lab/build/bench/classpath.txt build/experiments/medium4
python physics-lab/tools/run_stage_frequency_demo.py medium4 --java <путь-к-Java-21>
```

Путь Java можно задать через `JAVA_HOME`. Для медузы добавить `--body medusa`;
нужен экспорт `body-export-медуза.txt` в корне рабочей копии. В этой рабочей копии
сборки всех опытов уже сохранены в `build/experiments/<вариант>/`.

Лаунчер сохраняет предыдущие `player-log.txt`, `player-log-prev.txt`, `drag-log.txt`
перед запуском. Одновременно открывать несколько окон из одной рабочей копии
не следует: они пишут в одинаковые имена журналов. Выбранная версия и PID окна
сохраняются в `build/experiments/manual/<дата-вариант-тело>/launch.json`.

При автоматических проверках пороги и исходные H не менялись. Известный провал
обычного тела (speedcap 2 вместо 0) остался прежним. `swimTune --pop 1 --gen 0`
использован для сравнения метрик при прежних мышцах, без поиска новых параметров.
