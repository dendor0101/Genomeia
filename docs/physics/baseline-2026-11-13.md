## Как повторить

Перед командами Gradle задать `JAVA_TOOL_OPTIONS="-Dstdout.encoding=UTF-8 -Dstderr.encoding=UTF-8"`,
иначе вывод `physicsCheck` в файле не читается.

```
./gradlew --continue :core:compileKotlin :render:compileKotlin :lwjgl3:compileKotlin :physics-lab:compileKotlin :core:test :render:test :physics:test :physics-lab:test
./gradlew -q :physics-lab:physicsCheck -Pbody=body-export-кирпич.txt
./gradlew -q :physics-lab:physicsCheck -Pbody=body-export-медуза.txt
./gradlew -q :physics-lab:trapHunt -Pplan=quick
./gradlew -q :physics-lab:playerLogSelfTest -Pbody=body-export-медуза.txt
./gradlew -q :lwjgl3:growthCheck
./gradlew -q :lwjgl3:standParityCheck
./gradlew -q :lwjgl3:bugReplayCheck -Pworkers=4 -PgrowTicks=3000 -PspawnGrid=4 -PhashPeriod=1 -PreplayWorkers=1
```

Повтор последней записи без новой записи (путь к ней лежит в
`lwjgl3/build/bugReplayCheck/last-bug.txt`):

```
./gradlew -q :lwjgl3:bugReplayCheck -x bugReplayCheckRecord -PreplayWorkers=1 -PgrowTicks=3000 -PspawnGrid=4 -PhashPeriod=1
```

Проверки без задач Gradle — из корня ветки, classpath пишет задача
`:physics-lab:writeBenchmarkClasspath` (файл `physics-lab/build/bench/classpath.txt`):

```
java -Xmx3g -XX:G1HeapRegionSize=32m -Dfile.encoding=UTF-8 -cp <classpath> io.github.some_example_name.physics.lab.checks.<Имя>Kt <аргументы>
```

| Проверка | Аргументы |
|---|---|
| `ClientInputsCheck`, `GrowthCheck`, `FreeCheck`, `RuntimeWorldCheck` | `docs/physics/scenes/append-small.scene 3` |
| `SnapshotCheck` | `docs/physics/scenes/append-small.scene 120 300 3` |
| `PartialBodyCheck`, `CompactCheck`, `AppendCheck` | без аргументов |
