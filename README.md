# Genomeia

## En:

**Genomeia** – An evolution and life-form creation simulator where you design creatures with unique behaviors and observe their interactions, survival, and evolution.

### Project:
- Written in the Kotlin programming language.
- Developed using the IntelliJ IDEA IDE by JetBrains.
- Built on the [libGDX](https://libgdx.com/) engine.

To run the game, you need the Java Development Kit (JDK), version 21 or higher. Download instructions depend on your operating system:

- Windows:
Go to https://adoptium.net/temurin/releases/?version=21 and download the Windows file with the `.msi` extension.

- macOS:
Go to https://adoptium.net/temurin/releases/?version=21 and download the macOS file with the `.pkg` extension.

- Linux:
For most distributions, it is best to use the terminal:
```bash
sudo apt update
sudo apt install openjdk-21-jdk
```

- Android:
For Android, no additional dependencies need to be downloaded; simply install the `.apk` file.

Once everything is installed, you can launch the game by double-clicking the game file (if it has the `.jar` extension).

## Ru:

**Genomeia** - Симулятор эволюции и создания живых организмов, в котором вы проектируете существ с уникальным поведением и наблюдаете за их взаимодействием, выживанием и эволюцией. 

### Проект:
- Создан на языке программирования Kotlin.
- Игра создана в среде разработки IntelliJ IDEA от JetBrains.
- Игра основана на движке [libGDX](https://libgdx.com/).

Для запуска игры вам нужно иметь Java Development Kit (JDK) минимальной версии 21. Скачивание зависит от вашей ОС:

- Windows:
Перейдите по ссылке https://adoptium.net/temurin/releases/?version=21 и скачайте файл для Windows в расширении `.msi`.

- MacOS:
Перейдите по ссылке https://adoptium.net/temurin/releases/?version=21 и скачайте файл для MacOS в расширении `.pkg`.

- Linux:
В большинстве дистрибутивах лучше использовать терминал:
```bash
sudo apt update
sudo apt install openjdk-21-jdk
```

- Android:
Для Android скачивание зависимостей не требуется, достаточно установить .apk файл.

Если все установлено то запустить игру можно двойным кликом по файлу игры (если он в расширении .jar).
